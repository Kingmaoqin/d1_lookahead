### 6.1 本轮最重要的新对照：C6

**只用廉价特征、只把目标函数从池化 MSE 换成成对排序损失**，在完全不使用

> **旧实验报告的"隐藏态带来的决策增益"里，约 58% 与表征无关，
> 只是基线的目标函数没选对。**

### 6.2 功效分析（§27）—— 零结果不是欠功效

从文档级聚类自助的区间反推标准误（test = 600 states / 100 docs）：

| 端点 | SE | 若真实效应 = +0.020 的功效 | 最小可检效应(80%) |
|---|---|---|---|
| Δconcordance（C1） | 0.0046 | **99.6%** | 0.0115 |
| Δconcordance（C4 关系型） | 0.0051 | **98.9%** | 0.0126 |
| Δwithin-R²（C1） | 0.0040 | 100% | 0.0099 |
| Δtop1（C1） | 0.0123 | 49.4% | 0.0305 |

> **Δconcordance 上的零结果不是欠功效造成的**：数据能以 >99% 的功效检出
> +0.020 的真实效应，实测 +0.0107（上界 +0.0197）。同理 C4 的关系型零结果
> 也能以 98.9% 的功效排除 +0.020。
>
> 反过来，**Δtop1 端点相对欠功效**（MDE 0.031），因此对它的小效应解读要谨慎；
> 但实测的 +0.063 远超 MDE。
>
> fresh holdout 有 1,200 states / 200 docs，SE 预计再缩小约 √2 倍。

## 8. Nemotron-3B 任务效用

### 8.1 §17 的核心量化：Path-LL 与 task advantage 几乎不相关

`rescue_audit/task_utility_analysis.py`，taskA+taskB（2,240 行 / 560 states /
273 题，每 state 4 个候选）：

| 量 | 值 |
|---|---|
| `corr(A_PathLL, A_task)` 池化 Pearson | **+0.037** |
| 同状态内 Pearson | **+0.062** |
| Path-LL 作为 A_task 排序器的 concordance | **0.567**（随机 0.5） |
| A_task 噪声天花板 / SNR | 0.923 / 11.91 |
| A_task within-state 天花板 / SNR | 0.930 / 13.27 |
| A_PathLL 天花板 / SNR | 0.944 / 16.78 |

**这是本轮对 KILL 适用范围影响最大的一个数。** 旧报告把它列为待查隐忧
（"如果 Path-LL 与 task advantage 相关很弱，那么'probe 读不出 Path-LL A'
不能简单外推到 task A"），但没有量化。现在量化了：**r = 0.037**。

两个直接推论：
1. 本项目在 MDLM/SEDD 上做的全部 KILL 证据，**只约束 Path-LL 定义的优势**。
2. A_task 标签本身质量很好（天花板 0.92、SNR 11.9），**限制因素是 560 个
   状态的样本量**，不是标签噪声。

### 8.2 A_task 上的探针筛查（探索性，样本量严重不足）

### 10.4 两个设计里都复现的第二条：目标函数才是那个增益

### 判定的确切含义

**成立的**：冻结的掩码扩散表征线性携带 **状态级** 信息，这条通道在 1,200 个
全新 state 上稳定复现（Δwithin-R² +0.0232 [+0.0178,+0.0285]），
且是 08-24 那个结论的第三次独立确认。

**不成立的**：候选级动作优势的可读性。而且这一次它是在下述条件下被否定的——

* 探针族在**植入了对应结构的合成数据上全部按预期成功**
  （双线性 within-R² +0.553、非线性 +0.382、纯排序 +0.667），
  在零假设上**零假阳性**；
* 估计量本身经**两套独立的精确 DP 验证**确认无误；
* Δconcordance 端点的**功效为 99.6%**（能检出 +0.020 的真实效应）；
* 把 `h_i` 换成高斯噪声，**存活效应一点不减**；
* 一个**不使用隐藏态**、只换目标函数的探针拿到**完全相同**的 Δconcordance；
* 关系型交互项在两个骨干、三个视界、三种选择准则、四个层上**一律为零或有害**。

因此这个否定结论比 08-30 时强得多：它不再只是"我们没找到"，
而是"在一族被证明能找到该类结构的探针下、以充足功效、没有找到"。

### 但适用范围被显著收窄

`corr(A_PathLL, A_task) = +0.037`（§8.1）。上述全部证据**只约束
Path-LL 定义的优势**。任务效用方向不但没被杀死，反而因为这个相关性
结果而**重新打开**——而且在现有 560 个状态的小样本上出现了本项目最大的
候选级效应线索（`P7k_pair_hi` 在 A_task 上 Δconc +0.0538，第 12 层）。
该线索是在约 20 个探针 × 2 准则 × 13 层里取的最大值、测试集仅约 140 个
state，**属于探索性提示，不是结论**；它恰好指向正在采集的 `labels_taskC`。

### 给 PI 的三条建议

1. **把 Path-LL 方向按 negative result 写出来。** 它现在的强度足以支撑一篇
   诚实的否定/机制论文：*DLM 表征暴露 state value 与题目难度（level），
   不暴露 action advantage 与轨迹内波动（differential）*。
   与 frozen-VLA 探测研究（arXiv 2605.28527，只用线性探针、不区分 V 与 A）
   正面对照，本研究的分解是新的。
2. **把资源转到 task-utility。** §8.1 的 r=0.037 说明这是一个**不同的问题**，
   而不是同一问题的另一个度量。`labels_taskC` 已在采（180 题、每 state 6 个
   候选、offset 440）。目标按任务书 §13 是 3,000–5,000 个独立 state。
3. **报告"目标函数对照"这件事本身。** 在候选排序这类任务上，用池化 MSE
   基线去衡量表征增益会系统性高估——本轮两个独立设计都显示，
   把基线换成同容量的排序损失探针后，隐藏态的排序增益归零。
   这对整个 probing 文献是可复用的方法学提醒。
