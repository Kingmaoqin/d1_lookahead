# 对 Claude 并行实现与结论的交叉审计

日期：2026-09-01

## 总判断

Claude 的第二轮实现审计是有价值的：分块正则、gamma 网格、自助法重复文档
合并、SEDD 控制块缺失和非凸训练预算等问题都是真问题。它对 **Path-LL 冻结
迁移主端点未达到 +0.020** 的判断也成立。

但它在解释正结果时有一处系统性过度收缩：把“域内重新拟合 D2”与“旧域训练后
冻结迁移 D1”当成同一种复现。二者估计对象不同：

* D2 回答“新域里是否存在可学习信号”；
* D1 回答“旧域学到的同一读出器能否零适配迁移”。

因此，D2 为正而 D1 变弱时，正确结论是 **信号存在但读出具有域依赖**，不能写成
“信号已被证伪”。

## Claude 做对的部分

1. Path-LL 的预注册 D1 主端点只有约 +0.008 至 +0.010，低于 +0.020 实用阈值。
2. 修正分块惩罚后，Kronecker 交互在真实 Path-LL 数据上约为 0；同一实现能在
   植入双线性信号的合成数据上恢复约 +0.075，故该阴性结果可信。
3. 标签可靠性远高于 cheap 基线，阴性结果不能归因于测量天花板。
4. 旧聚类自助把同一文档的重复副本按原 state id 合并，区间偏宽；修正不反转
   Path-LL 主结论。
5. 只换成排序损失的 cheap 模型能解释旧 top-1 增益的一部分，说明目标函数匹配
   是必要控制。

## Claude 过度否定的部分

### 1. candidate-informative 亚组不是“被证伪”，而是迁移不稳定

同域重拟合 D2 的结果是：

* MDLM 发现集：`cheap+H - cheap` 约 +0.0256，修正 CI 排除 0；
* 独立 fresh D2：约 +0.0200，修正 CI 也排除 0。

冻结迁移 D1 则降到 L8 +0.0053 / L6 +0.0106。这个结果否定的是“旧读出器可
零适配迁移”，不是“新域内不存在该信号”。报告应把它列为 **两次 D2 为正、D1
迁移衰减的设计依赖线索**。

### 2. D2 的决策端点不能因 primary concordance 未过阈值而消失

fresh D2 中，隐藏探针相对 cheap 的 top-1、normalized regret、within-R² 三个
端点都为正并通过原判据。它们不能升级成预注册主结论，但应作为明确的正结果
报告，而不是只留下 “KILL”。

### 3. Task utility 是另一个问题，不受 Path-LL KILL 外推

旧 taskA/taskB 中 `corr(A_PathLL, A_task)` 只有约 +0.04，而锁定的候选隐藏排序
探针曾给出约 +0.054 的探索增益。因此 task utility 必须独立检验。新完成的
taskC 有 180 题 / 720 states / 4,320 候选，标签 within-state ceiling 约 0.943；
数据质量足以继续判断该方向。

## 目前可以自信保留的正结果

1. **状态级价值通道稳定存在**：fresh D1 的 Δwithin-R² 约 +0.0232，CI 明确
   排除 0。这是冻结表征的真实、可迁移正信号。
2. **域内 candidate-informative 读出为正**：两份 D2 数据均达到约 +0.020，
   但冻结跨域迁移变弱；应表述为域依赖，而非不存在。
3. **Task-C 关系型候选排序出现稳定探索信号**：三次文档划分中，rank-4
   双线性探针相对 cheap 的 Δconcordance 分别为 +0.0421、+0.0300、+0.0422，
   均值 **+0.0381**，而 shuffled-h_g / Gaussian-h_g 总体接近 0。
4. **目标函数匹配后仍有一条隐藏通道**：锁定第 12 层的成对 `cheap+hidden`
   相对成对 cheap 三划分均为正（+0.0459、+0.0037、+0.0195），均值
   **+0.0230**。这排除了“全部只是 MSE 基线过弱”的最强版本。

第 3 项正在用五折、每文档仅预测一次的原协议做最后区间估计；在该结果完成前，
它应标为强探索性正结果，而不是预注册确认性结果。

### 五折复核后的精确限定

五折 OOF 保留了正方向，但暴露出非凸训练种子敏感性：

* 使用独立初始化 100–104：bilinear−cheap = +0.0149，
  bilinear−no-interaction = +0.0072；
* 严格匹配广筛初始化 0–4：bilinear−cheap = +0.0270，
  bilinear−no-interaction = +0.0265。

两套区间都覆盖 0；而第二套中 shuffled/Gaussian 控制偶尔能追平真实 h_g。
因此可以自信说 **task utility 上存在值得扩样的候选排序信号**，但还不能把它
唯一归因于真实状态调制。这个不确定性已通过 `TASKD_PREREGISTRATION.md` 在新数据
出生前锁定：扩到总计 3,000 states，用冻结模型一次性区分真实 h_g、无交互、
shuffled 与 Gaussian 控制。

另一个必须保留的反证是：封存 Task-D 主模型时，在 Task-C seed-0 内部 test 上，
bilinear = 0.5526、no-interaction = 0.5239，但同训练预算的 neural cheap-only =
**0.5908**。所以广筛中相对 cheap ridge 的 +0.042 不能直接解释为隐藏态净增益；
它同时混入了基线模型类差异。Task-D primary 已把这个更强 cheap-only 锁为主基线。

## 口径修正

Task utility 的 A_task 大量并列。旧 `top1` 把第一个最大值指定为唯一 oracle，且
把所有候选等值的 state 也计入，会让常数预测出现虚高准确率。最终报告以
concordance（只比较真实标签不等的候选对）为主，并补充“并列友好、只在可决策
state 上计算”的 top-1；不再用旧 top-1 支撑正结论。
